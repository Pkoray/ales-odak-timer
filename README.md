# ALES Odak

Modern ve minimalist tasarıma sahip, ALES sınavına hazırlananlar için geliştirilmiş bir odaklanma ve çalışma takip uygulaması.

## Özellikler

- **Pomodoro sayacı** — varsayılan 150 dakika, Başla / Duraklat / Sıfırla kontrolleriyle
- **Sayısal ve Sözel kartları** — her oturumda çözülen soru sayısını ayrı ayrı takip eder, +1 / +5 / +10 ve -1 / -5 / -10 butonlarıyla hızlıca güncellenir
- **Değişen motivasyon sözleri** — sayfa her yenilendiğinde farklı bir söz gösterilir
- **Koyu tema** — göz yormayan, uzun çalışma seansları için tasarlanmış arayüz

## Kullanım

Ekstra kurulum gerekmez. `ales-odak.html` dosyasını herhangi bir modern tarayıcıda açman yeterli:

```
ales-odak.html dosyasına çift tıkla
```

## Kullanılan teknolojiler

- HTML5 / vanilla JavaScript
- [Tailwind CSS](https://tailwindcss.com/) (CDN üzerinden)
- Google Fonts — Manrope & JetBrains Mono
